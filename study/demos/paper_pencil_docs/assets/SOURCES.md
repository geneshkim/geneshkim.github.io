# Paper Pencil Audio Sources

The paper/pencil prototype uses the local OGG files in `assets/ogg/`.
It also uses `pencil_write_bigsoundbank.mp3` as the primary writing sample for broad browser support.
It uses `paper_move_luckius.mp3` when a collaborator moves sections or when the user moves away from a collaborator.
