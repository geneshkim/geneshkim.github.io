Accessible Screen Reader UI Prototypes

Overview

Simple static HTML prototypes for screen-reader-friendly menus, checkout flows, and forum interfaces. Each page starts with a short description and includes optional speech-label variations using apostrophe syllables and Eloquence-style ECI examples.

Speech effects are disabled by default because unsupported synthesizers may read command characters literally.
